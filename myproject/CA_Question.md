> Create a Django application that generates a personalized greeting based on information supplied through the URL. Create a view named greeting and map it to a URL that accepts two parameters: name and timeofday. For example, /greet/Navneet/morning/ should display “Good Morning, Navneet!”, while /greet/Rahul/evening/ should display “Good Evening, Rahul!”. The view must use conditional logic to generate the appropriate greeting for morning, afternoon, and evening. If any other value is supplied for timeofday, display “Invalid Time of Day”. Pass the generated greeting from the view to an HTML template using the Django context mechanism. The template should display the greeting inside an <h1> element using a template variable.


> Create a Django application that displays the departments of a college. Store exactly five department names in a Python list inside a view. Create /departments/ to display the departments using a Django template. The view must send the list to the template through context, and the template must use a for loop to display each department as a separate numbered item. The template must also use a conditional statement to display “Multiple departments are available” when the list contains more than three departments and “Limited departments are available” otherwise. Create another URL /department/<department_name>/ that receives a department name through the URL and displays “You selected: <departmentname>”. If the supplied department name is not present in the predefined list, display “Department Not Available”. This question should use separate templates for the department list and department details.
